- **Fixed:** Diagnostics no longer get a second, client-side ignore-comment pass. Suppression from `# type: ignore` and `# pyright: ignore[...]` is applied by Pyright alone, honoring `enableTypeIgnoreComments` and rule-selective ignores; ignore text inside string literals no longer hides diagnostics. Migration: results can now include diagnostics Pyright itself reports that the old filter hid (including unnecessary-ignore reports), so tools counting diagnostics, such as `diagnostics_after`, may see more results.
