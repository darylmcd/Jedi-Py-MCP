- **Changed — BREAKING:** A request whose explicit paths (`file_path`, `source_file`, `destination_file`, `root_path`, `file_paths`, or `refactor_transaction` step paths) resolve to more than one workspace, including any nested project root (Git worktree or `pyproject.toml`/`setup.py`/`setup.cfg` project) inside a registered checkout, is now rejected with `[INVALID_INPUT]` before any tool or backend runs, in either path order; previously an outer-first request was accepted and sent nested paths to the outer backend. Split the call into one call per workspace.
