- **Changed — BREAKING:** the server is built by `server.build_server(workspace_root)` and its lifespan by `server.workspace_lifespan(workspace_root)`; the import-time `server.mcp`, `server.app_lifespan` and the module global `_workspace_root` are removed, so servers built in one process no longer share the CLI root. Tools, schemas and the command line are unchanged. Migration: replace `server.mcp` with `server.build_server()` and `server.app_lifespan` with `server.workspace_lifespan(root)`. See ADR 0008.
