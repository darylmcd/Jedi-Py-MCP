- **Changed — BREAKING:** `change_signature` operations `add`, `remove`, `reorder`, `normalize` and `inline_default` now fail with `ToolInputError` (nothing written) when rope would also rewrite another definition with the target's name (redefinition, conditional `def`, `@overload` stub, property setter; previously only `rename` refused, the others rewrote every header). Same-named methods of other classes are unaffected. Migration: edit such signatures by hand or remove the duplicate definitions first (ADR 0004).
