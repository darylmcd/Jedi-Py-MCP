- **Changed — BREAKING:** `change_signature` operations `add`, `remove`, `reorder`, `normalize` and `inline_default` now fail with `ToolInputError` (nothing written) when rope would also rewrite another definition with the target's name (redefinition, conditional `def`, `@overload` stub, property setter; previously only `rename` refused, the others rewrote every header), including an annotated same-named definition whose parameters are unchanged (rope drops annotations). A rope result that does not parse is now refused for every operation instead of returning an unparseable preview. Same-named methods of other classes are unaffected. Migration: edit such signatures by hand or remove the duplicate definitions first (ADR 0004).
