- **Changed — BREAKING:** a tool call that names no file no longer falls back to the most recently used or pre-warmed workspace. Path-less calls (`search_symbols`, `fix_module_names`, `undo_refactoring`, `redo_refactoring`, the change-stack tools, `get_workspace_diagnostics`, `get_diagnostics` without a file, `create_type_stubs`, `restart_server`, ...) now resolve only to the sole workspace a path-bearing call already selected; with several live workspaces, only the startup pre-warmed workspace, or none, they fail with the new `[AMBIGUOUS_WORKSPACE]` error naming the live roots and `root_path`. In a single-project registration the first path-less call therefore fails until a path-bearing call or `root_path` selects the positional root. The 26 tools that can be called without a path (`autoimport_search`, `begin_change_stack`, `check_layer_violations`, `commit_change_stack`, `create_type_stubs`, `find_constructors`, `find_unused_imports`, `fix_circular_imports`, `fix_module_names`, `get_coupling_metrics`, `get_diagnostics`, `get_module_dependencies`, `get_refactoring_history`, `get_test_coverage_map`, `list_environments`, `project_search`, `redo_refactoring`, `restart_server`, `restructure`, `rollback_change_stack`, `search_symbols`, `security_autofix`, `security_scan`, `structural_replace`, `structural_search`, `undo_refactoring`) gain an optional absolute `root_path`, and `root_path` on the four tools that already had it (`dead_code_detection`, `get_symbol_outline`, `get_workspace_diagnostics`, `unused_symbol_sweep`) now also selects the workspace. `test_impact_select` now rejects an empty `symbols` list. Migration: pass an absolute `root_path` on path-less calls or make one path-bearing call first; drop the positional workspace root from registrations shared by several repositories; pass at least one anchor to `test_impact_select`. See ADR 0007.
