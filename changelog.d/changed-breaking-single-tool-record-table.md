- **Changed — BREAKING:** every tool is now one record in `tool_registry.TOOL_RECORDS`; `server.EXPLICIT_TOOL_RECORDS` and the `extra_records` parameter of `build_tools` / `tool_names_for_profile` are removed, and the eleven delegates that lived in `server.py` (`get_completions`, `get_inlay_hints`, `get_symbol_outline`, `argument_normalizer`, `argument_default_inliner`, `find_unused_imports`, `get_test_coverage_map`, `security_scan`, `security_autofix`, `structural_replace`, `server_status`) moved to `tool_registry`. The tool surface (names, schemas, annotations, profiles, order) and the command line are unchanged; the moved tools' debug logs now come from the logger `python_refactor_mcp.tool_registry` instead of `python_refactor_mcp.server`. Migration: call `build_tools(profile)` / `tool_names_for_profile(profile)` and import the delegates from `tool_registry`. See ADR 0009.
