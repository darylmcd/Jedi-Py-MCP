- **Changed — BREAKING:** `change_signature` now rejects with `ToolInputError` (nothing is written) an `add` or `reorder` whose final signature would place a required parameter after a defaulted one (`def f(a=1, b)`), and a `reorder` whose `new_order` is not a permutation of the positional parameter indexes (a duplicate index wrote `def f(a, a)`, a short list dropped a parameter). Defaults are now read from the definition, so targets with `*args` are validated correctly. Migration: give the added parameter a default or place it before the first defaulted parameter, and pass every positional index exactly once in `new_order`; catch `ToolInputError` (ADR 0004).
