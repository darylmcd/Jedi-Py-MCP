- **Changed — BREAKING:** `change_signature` now rejects with `ToolInputError` (nothing is written): every operation on a function that has `*args` (rope emitted unparseable code such as `def f(a, b, *args=1)` and shifted the defaults before `*args`); an `add` or `reorder` whose final signature would place a required parameter after a defaulted one (`def f(a=1, b)`); and a `reorder` whose `new_order` is not a permutation of the positional parameter indexes (a duplicate index wrote `def f(a, a)`, a short list dropped a parameter). Migration: change a function with `*args` by hand, give the added parameter a default or place it before the first defaulted parameter, and pass every positional index exactly once in `new_order`; catch `ToolInputError` (ADR 0004).
