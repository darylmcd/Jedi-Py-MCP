- **Fixed:** Applying edits (`change_signature`, `split_module`, `format_code`, `apply_lint_fixes`, `docstring_sync`, the LibCST-based tools and other text-edit results) no longer rewrites a CRLF or lone-CR file as LF: the file's own line endings are written back, including after a rolled-back failure. A mixed-ending file keeps each unchanged line's ending, a changed line takes the ending of the line it replaces, and inserted lines take the file's most common ending (a tie goes to the one seen first); a changed section over 40 million line pairs is paired by position. Previews are unchanged (`new_text` stays `\n`); an empty file gets `\n`.
