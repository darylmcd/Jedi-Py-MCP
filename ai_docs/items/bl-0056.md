## Evidence

- `tool_runtime.py:229-232` (`_resolve_backends`): with no path argument it returns `registry.get_most_recent()`, else initializes the CLI root. `server.py:80-83` eagerly initializes the CLI root at lifespan start, so until a path-bearing call runs, that fallback is the pre-warmed workspace.
- `fix_module_names` takes only `apply`; called path-less from another repo with `apply=true` it renames modules in whichever workspace is most recent.
- Live-schema probe at `de4d87d` (plan report): 31 tools have no required selector; 4 already carry `root_path`; 26 need it; `server_status` exempt.
